# Notion Wedding Planner Pack: user guide

## Overview

This pack provides a streamlined planning system for independent wedding planners and engaged couples in Egypt. It combines a Markdown checklist for task management with a CSV tracker for organized vendor oversight.

## Quick start

1. [J1. Review the master wedding planning checklist in Markdown format.](phase3_step3_product_checklist_r_a1.md#j1): Review the master wedding planning checklist in Markdown format.
2. [J2. Check off completed tasks to monitor wedding readiness.](phase3_step3_product_checklist_r_a1.md#j2): Check off completed tasks to monitor wedding readiness.
3. [J3. Populate the vendor tracker CSV with local Egyptian vendor details.](phase3_step3_product_checklist_r_a1.md#j3): Populate the vendor tracker CSV with local Egyptian vendor details.
4. [J4. Import the CSV into a workspace to maintain a centralized vendor database.](phase3_step3_product_checklist_r_a1.md#j4): Import the CSV into a workspace to maintain a centralized vendor database.

## How to use

Use the Markdown file as your daily interactive to-do list by marking tasks as complete. Simultaneously, enter all contact information and contract details into the CSV file, then upload that file to your preferred database tool to keep all vendor data in one place.

The tracker CSV has one row per checklist item; open it in any spreadsheet app.

## Troubleshooting

- If the CSV opens in a single column, use the 'Text to Columns' feature in your spreadsheet software.
- Ensure all special characters in vendor names are saved using UTF-8 encoding to prevent display errors.
- If Markdown checkboxes do not click, ensure you are using a compatible Markdown editor or Notion.

## Limitations

This pack is a management tool and does not guarantee wedding success or provide professional legal or financial advice. Users are responsible for verifying all vendor details and local regulations.
