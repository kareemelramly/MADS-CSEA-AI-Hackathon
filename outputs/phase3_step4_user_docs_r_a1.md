# Notion Wedding Planner Pack: user guide

## Overview

This pack provides a structured Markdown checklist and a CSV tracker designed for wedding planners and engaged couples. It replaces chaotic planning with a professional system to manage timelines and vendor logistics efficiently.

## Quick start

1. [J1. Review the master wedding timeline checklist](phase3_step3_product_checklist_r_a1.md#j1): Review the master wedding timeline checklist.
2. [J2. Identify and list required vendor categories](phase3_step3_product_checklist_r_a1.md#j2): Identify and list your required vendor categories.
3. [J3. Log vendor contact details and quotes in the tracker](phase3_step3_product_checklist_r_a1.md#j3): Log vendor contact details and quotes into the CSV tracker.
4. [J4. Check off completed tasks as vendors are secured](phase3_step3_product_checklist_r_a1.md#j4): Check off completed tasks as vendors are secured.
5. [J5. Export the final vendor list for event-day coordination](phase3_step3_product_checklist_r_a1.md#j5): Export the final vendor list for event-day coordination.

## How to use

Start by following the chronological steps in the Markdown checklist to build your timeline. As you research and contact suppliers, enter their information into the CSV tracker. Once a vendor is booked, mark the corresponding task as complete in the checklist to maintain a real-time view of your progress.

The tracker CSV has one row per checklist item; open it in any spreadsheet app.

## Troubleshooting

- If the CSV opens in a single column, use the 'Text to Columns' feature in your spreadsheet software.
- Ensure you save the CSV in UTF-8 format to preserve special characters.
- If Markdown checkboxes do not click, ensure you are using a compatible Markdown editor or Notion.
