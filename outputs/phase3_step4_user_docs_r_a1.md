# Notion Wedding Planner Pack: user guide

## Overview

This pack provides a structured Markdown checklist and a CSV vendor tracker designed for independent wedding planners. It helps organize wedding categories and supplier data without relying on external lead generation platforms.

## Quick start

1. [J1. Review the master wedding checklist to identify missing tasks](phase3_step3_product_checklist_r_a1.md#j1): Review the master wedding checklist to identify missing tasks.
2. [J2. Categorize tasks into specific wedding elements like venue or attire](phase3_step3_product_checklist_r_a1.md#j2): Categorize tasks into specific wedding elements like venue or attire.
3. [J3. Populate the vendor tracker with contact information from local suppliers](phase3_step3_product_checklist_r_a1.md#j3): Populate the vendor tracker with contact information from local suppliers.
4. [J4. Track progress by marking completed items in the Markdown checklist](phase3_step3_product_checklist_r_a1.md#j4): Track progress by marking completed items in the Markdown checklist.

## How to use

Begin by auditing your current wedding requirements against the Markdown checklist. Once tasks are categorized, use the CSV tracker to log all local supplier details. As you complete each milestone, update the Markdown file by checking off the corresponding items to maintain a real-time view of your progress.

The tracker CSV has one row per checklist item; open it in any spreadsheet app.

## Troubleshooting

- If the CSV opens in a single column, use the 'Text to Columns' feature in your spreadsheet software.
- Ensure your Markdown editor supports checkbox syntax for interactive marking.
- If special characters appear incorrectly in the CSV, try re-importing with UTF-8 encoding.
