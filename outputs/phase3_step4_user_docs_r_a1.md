# Notion Wedding Planner Pack: user guide

## Overview

This pack provides a structured Markdown checklist and a CSV vendor tracker designed for independent wedding planners. It helps organize wedding milestones and vendor logistics in a centralized, offline-capable format.

## Quick start

1. [J1. Review the wedding timeline milestones in the Markdown checklist](phase3_step3_product_checklist_r_a1.md#j1): Review the wedding timeline milestones in the Markdown checklist.
2. [J2. Identify and list required vendors based on the checklist needs](phase3_step3_product_checklist_r_a1.md#j2): Identify and list required vendors based on the checklist needs.
3. [J3. Populate the CSV tracker with vendor contact information and pricing](phase3_step3_product_checklist_r_a1.md#j3): Populate the CSV tracker with vendor contact information and pricing.
4. [J4. Track completion of tasks through the checklist phases](phase3_step3_product_checklist_r_a1.md#j4): Track completion of tasks through the checklist phases.

## How to use

Open the Markdown file to follow the chronological wedding phases. As you source vendors, enter their details into the CSV tracker. Use the checkboxes in the Markdown file to mark tasks as complete to maintain a real-time view of your progress.

The tracker CSV has one row per checklist item; open it in any spreadsheet app.

## Troubleshooting

- If the CSV opens in a single column, use the 'Text to Columns' feature in your spreadsheet software.
- Ensure your Markdown editor supports checkbox syntax for interactive ticking.
- If special characters appear broken in the CSV, re-import using UTF-8 encoding.
