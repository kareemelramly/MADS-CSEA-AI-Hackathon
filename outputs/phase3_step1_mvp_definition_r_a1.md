# Phase 3 · Step 1 · MVP definition (archetype A1 checklist pack)

**Mode:** minimal

**User story:** As an independent wedding planner or engaged couple in Egypt, I want a centralized checklist and vendor management system so that I can track wedding progress and vendor details without complex software.

## Must features

- Centralized Wedding Management Pack: A dual-format toolkit consisting of a Markdown checklist for task progress and a CSV tracker for vendor details to ensure organized planning. (evidence: S028, S002)

## Acceptance criteria

1. Given The user has downloaded the product pack, when they open the Markdown file, then they can see a structured list of wedding planning tasks to check off.
2. Given The user needs to manage vendor contacts, when they import the CSV tracker into their preferred tool, then all vendor columns (name, contact, service, status) are correctly mapped.
3. Given The user is planning a wedding in Egypt, when they use the checklist, then they can track the completion status of every major planning milestone.

## Journey

J1. Review the master wedding planning checklist in Markdown format.
J2. Check off completed tasks to monitor wedding readiness.
J3. Populate the vendor tracker CSV with local Egyptian vendor details.
J4. Import the CSV into a workspace to maintain a centralized vendor database.

- Reminders, sync or sharing with other apps: MOCKED (not built; the pack is static files)
