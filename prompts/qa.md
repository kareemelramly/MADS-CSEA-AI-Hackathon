# qa (no model call)

Code-only agent. Runs the 14 checks that apply to archetype A1 (QA-01 to QA-06, QA-08 to QA-15): manifest, size, format, journey trace, internal links, no external resources, banned content, excluded category, claims sourced, mocks and override labelled, docs headings, licence, acceptance criteria, naming. QA-07 (script integrity) is not applicable to A1. Failing messages are fed back to the Builder; the founder cannot pass a failed check.
